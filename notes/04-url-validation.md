# URL validation

- Browser validation helps users enter data.
- Backend validation enforces the rules.
- new URL() parses an address; it does not prove it is safe.
- An allowlist explicitly defines permitted destinations.
- SSRF happens when an attacker makes our server send unintended requests.
- Our prototype allows two HTTPS origins and does not follow redirects.
- General public-URL support will require DNS/IP checks and further protections.
